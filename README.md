# E-Commerce-Sales-Dashboard-PowerBI
Interactive Power BI dashboard analyzing Brazil E-Commerce sales data using SQL, PostgreSQL, Excel, and Power BI.
## 📌 Project Overview

The objective of this project is to transform raw e-commerce data into meaningful business insights through data cleaning, SQL analysis, and interactive Power BI visualizations.

---

## 🛠️ Tools & Technologies

- Power BI
- PostgreSQL
- SQL
- Python (Pandas)
- Excel
- Git & GitHub

---

## 📂 Dataset

**Brazil E-Commerce Public Dataset (Olist)**

Files used:
- olist_customers_dataset.csv
- olist_orders_dataset.csv
- olist_order_items_dataset.csv
- olist_order_payments_dataset.csv
- olist_products_dataset.csv

---

## 📊 Dashboard KPIs

- 💰 Total Revenue
- 📦 Total Orders
- 👥 Total Customers
- 🏪 Total Sellers
- 💳 Payment Method Distribution
- 📈 Revenue Trend (2016–2018)
- 🏆 Top Product Categories
- 🌎 Top States by Revenue

---

## 🔍 Business Insights

- Credit Card is the most preferred payment method.
- São Paulo (SP) generates the highest revenue.
- Revenue increased significantly between 2016 and 2018.
- Beauty and Watches are among the top-selling product categories.
